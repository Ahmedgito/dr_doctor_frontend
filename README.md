# dr.doctor frontend

Medical assistant UI. Chat responses are provided by implementing `services/chatApi.ts` against your backend API.

## Run locally

**Prerequisites:** Node.js

1. Install dependencies: `npm install`
2. Run the app: `npm run dev`

The development server listens on port 3000 (see `vite.config.ts`).
